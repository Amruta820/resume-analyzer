# 📄 Resume Analyzer & Job Recommendation System

An AI-powered web application that analyzes a candidate's resume against a job description and provides an overall compatibility score, skill analysis, NLP similarity score, and recommended job roles.

## 🚀 Features

- 📄 Upload and extract text from PDF resumes
- 💼 Enter a job description
- 🔍 Detect technical skills from resumes and job descriptions
- ✅ Identify matching skills
- ❌ Identify missing skills
- 📊 Calculate resume-to-job skill match percentage
- 🤖 Calculate semantic similarity using NLP
- 🎯 Generate an overall compatibility score
- 💡 Provide recommendations for missing skills
- 🥇 Recommend the top 3 suitable job roles
- 📥 Generate a PDF analysis report

## 🛠️ Technologies Used

- Python
- Flask
- HTML & CSS
- PyPDF
- Scikit-learn
- Sentence Transformers
- NLP
- Git & GitHub

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Amruta820/resume-analyzer.git
cd resume-analyzer
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```
